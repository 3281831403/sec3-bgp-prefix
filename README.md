边界路由器接受了一条比聚合前缀更细的路由，流量被引到了错误的自治系统，过滤规则却显示已生效：通告前缀必须被至少一条允许规则覆盖，细于策略允许长度的前缀必须拒绝，拒绝规则优先于允许规则，路径属性里的自治系统链必须可校验，前缀长度必须与规则区间比较，批量过滤各通告独立。不变量：任何未被允许的前缀都被拒绝；拒绝规则永远不会被允许规则覆盖。

## 契约

规则由动作、前缀与长度区间组成，动作只有允许与拒绝两种。前缀覆盖按网络包含关系判断，不按文本是否相等判断。长度区间是闭区间，前缀长度必须落在区间内，细于区间上界的前缀按拒绝处理。

拒绝规则优先于任何允许规则。空规则集不产生允许结果。自治系统链必须逐项通过策略校验，链为空或包含策略之外的自治系统时判定为拒绝。批量过滤时每条通告独立判定，前一条通告的结果不得影响后一条。
